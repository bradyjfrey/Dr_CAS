# Dr_CAS
Website for Dr. Carlos Alberto Sanchez

- Build: Eleventy. `npm install`, then `npm start` (local preview) or `npm run build` (output in `_site`).
- Templates: `src/`. Content: `content/`. Styles and assets: `style.css`, `images/`, `fonts/`.
- Editing: Pages CMS, configured in `.pages.yml`. `/admin` on the live site redirects to the editor.
